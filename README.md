# FreeDev — Developer Toolbox

A free-first browser toolbox for everyday development tasks. Built with React and Vite, styled in the FreeToolz Emerald & Silver dark theme.

## Included tools
- **JSON:** formatter, minifier, validator, JSON → CSV, JSON → TypeScript
- **CSS:** formatter, minifier, gradient generator, shadow generator
- **Regex:** tester, token explainer, starter-pattern generator
- **URLs:** encoder, decoder, parser
- **Time:** current Unix timestamp, timestamp-to-date, timezone formatter
- **Text:** diff, case converter, word counter, character counter
- **Data:** CSV viewer, CSV → JSON, YAML ↔ JSON

## Run locally
```bash
npm install
npm run dev
```

## Deploy
Import this repository into Vercel and use the Vite defaults. The included `vercel.json` supports client-side routes if routes are added later.

## Privacy
The included transformations run client-side in the browser. Pasted data is not sent to a FreeDev backend.
